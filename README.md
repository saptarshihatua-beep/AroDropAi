# 🌱 Smart AI Irrigation System

## 🚀 Overview
This project is an AI-based irrigation system that helps farmers use water efficiently by analyzing soil moisture, weather conditions, and crop needs.

---

## 🎯 Problem
Traditional irrigation wastes water due to fixed schedules and lack of real-time monitoring.

---

## 💡 Solution
This system uses:
- Soil moisture data
- Weather conditions
- Crop type

To automatically decide how much water is needed.

---

## ⚙️ Features
- 🌡️ Real-time monitoring
- 🤖 Smart irrigation control
- 💧 Water saving system
- 📊 Simple UI dashboard
